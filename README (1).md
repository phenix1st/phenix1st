## 🚀 Featured Projects

### 🌱 Smart Greenhouse --- IoT & Connected Agriculture

A team project combining sensor-based monitoring, automation, and a
web/mobile experience to support smarter plant care.

-   Connected Arduino sensors and actuators for environmental monitoring
    and control.
-   Django REST backend with Firebase integration.
-   Dashboard and app workflows for automatic, semi-automatic, and
    manual operation.
-   Plant-disease identification and multilingual user experience.

**Focus:** IoT · Python · Django REST Framework · React · Firebase ·
Arduino

### 🏆 RAMY UP / AlgiersUp --- Computer Vision for Retail

A team project built to help analyze retail shelves and product-brand
visibility using computer vision. The team placed **3rd in RAMY UP
2025**.

-   Applied YOLOv8-based object detection to retail shelf analysis.
-   Explored a mobile-oriented workflow for merchandisers.

**Focus:** Computer Vision · Python · YOLOv8 · Applied AI

### 🔥 Algeria Forest Fires

A wildfire-monitoring dashboard concept focused on visualizing fire
activity and related information across Algeria.

-   Interactive map and dashboard for fire locations, statistics, and
    historical information.
-   Built around a React/Vite frontend and FastAPI backend.
-   Designed with multilingual support in mind.

**Repository:** [Algeria fire
forests](https://github.com/phenix1st/Algeria-fire-forests-)

### 🏥 Hospital Management System

A web application project focused on organizing hospital-related
workflows, with authentication, a realtime database, media handling, and
a multilingual interface.

**Repository:**
